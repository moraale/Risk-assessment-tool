# Cybersecurity Risk Assessment Tool

## Project Overview

This project is a Python-based cybersecurity risk assessment tool designed to identify, evaluate, and classify common organizational cybersecurity risks.

The tool uses a quantitative scoring model to evaluate risk based on likelihood and impact.

## Project Purpose

The purpose of this project is to demonstrate how basic programming skills can support cybersecurity risk management, governance, and organizational decision-making.

## Technical Skills Demonstrated

- Python programming
- Risk identification
- Quantitative risk scoring
- Conditional logic
- Data classification
- Cybersecurity governance concepts

## Risk Assessment Methodology

The tool calculates risk using the following formula:

Risk Score = Likelihood x Impact

Both likelihood and impact are rated on a scale of 1 to 5.

| Risk Score | Risk Classification |
|---|---|
| 1-5 | Low |
| 6-11 | Medium |
| 12-19 | High |
| 20-25 | Critical |

These thresholds are illustrative and are not an official NIST rating scale.

## Sample Risks Evaluated

- Phishing attacks
- Weak passwords
- Unpatched software
- Insider threats
- Data loss
